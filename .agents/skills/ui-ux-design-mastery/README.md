## When to Activate
- Designing a new web page, landing page, SaaS application, dashboard, or mobile interface.
- Redesigning or modernizing an existing user interface to look distinctive, polished, and human-crafted.
- Creating or refining design systems, UI components, typography scales, or color palettes.
- The user requests: *"make this look professional"*, *"improve the UI/UX"*, or *"make it look less like generic AI"*.
